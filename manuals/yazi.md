# Yazi 操作マニュアル

## 基本操作

| キー | 操作 |
|------|------|
| `h` / `l` | 親ディレクトリへ / ディレクトリに入る・ファイルを開く |
| `j` / `k` | 下 / 上に移動 |
| `J` / `K` | プレビューを下 / 上にスクロール |
| `gg` / `G` | 先頭 / 末尾へ |
| `q` | 終了 |
| `~` | ヘルプ (全キーバインド一覧) |

## ファイル操作

| キー | 操作 |
|------|------|
| `<Enter>` | smart-enter (ディレクトリなら入る、ファイルなら開く) |
| `o` | ファイルを開く (opener選択) |
| `a` | 新規ファイル/ディレクトリ作成 (末尾に`/`でディレクトリ) |
| `r` | リネーム |
| `d` | ゴミ箱に移動 |
| `D` | 完全削除 |
| `y` | コピー (yank) |
| `x` | カット |
| `p` | ペースト |
| `P` | ペースト (上書き) |
| `-` | シンボリックリンク作成 |
| `.` | 隠しファイルの表示/非表示切替 |

## 選択

| キー | 操作 |
|------|------|
| `<Space>` | 現在のファイルを選択/解除 |
| `v` | ビジュアル選択モード |
| `V` | ビジュアル選択モード (解除方向) |
| `<C-a>` | 全選択 |
| `<C-r>` | 選択反転 |

## 検索・フィルタ

| キー | 操作 |
|------|------|
| `/` | フィルタ (入力中にリアルタイム絞り込み) |
| `f` | フィルタ (確定後に絞り込み) |
| `s` | ファイル内容を検索 (fd/rg使用) |
| `<C-f>` | fzf + bat でファジーファイル検索 (カスタム) |
| `z` | zoxide でディレクトリジャンプ (カスタム) |

## ブックマーク (goto)

| キー | 移動先 |
|------|--------|
| `g d` | ~/Downloads |
| `g c` | ~/.config |
| `g D` | ~/Desktop |
| `g p` | ~/Projects |
| `g t` | /tmp |
| `g h` | ~ (デフォルト) |
| `g /` | / (デフォルト) |

## タブ操作

| キー | 操作 |
|------|------|
| `t` | 現在のディレクトリで新規タブ |
| `T` | ホームで新規タブ |
| `1`-`4` | タブ1-4に切替 |
| `[` / `]` | 前/次のタブ |
| `<C-c>` | タブを閉じる |

## クリップボード

| キー | 操作 |
|------|------|
| `y p` | ファイルのフルパスをコピー |
| `y n` | ファイル名のみコピー |

## バルク操作

| キー | 操作 |
|------|------|
| `b r` | 選択ファイルを一括リネーム (vidir) |
| `b z` | 選択ファイルをzip圧縮 |
| `b t` | 選択ファイルをtar.gz圧縮 |

## パーミッション

| キー | 操作 |
|------|------|
| `c m` | chmod (インタラクティブにパーミッション変更) |

## シェル

| キー | 操作 |
|------|------|
| `<C-s>` | 現在のディレクトリでシェルを開く |
| `:` | コマンド入力 (シェルコマンド実行) |
| `;` | コマンド入力 (ブロッキング) |

## ソート

| キー | 操作 |
|------|------|
| `,m` | 更新日時順 |
| `,M` | 更新日時順 (逆順) |
| `,s` | サイズ順 |
| `,S` | サイズ順 (逆順) |
| `,a` | アルファベット順 |
| `,A` | アルファベット順 (逆順) |
| `,n` | 自然順 |
| `,N` | 自然順 (逆順) |

## プラグイン一覧

| プラグイン | 説明 |
|-----------|------|
| **git** | ファイル一覧にgitステータスを表示 |
| **smart-enter** | Enter/lでディレクトリなら入る、ファイルなら開く |
| **chmod** | インタラクティブなパーミッション変更 |
| **full-border** | 全ペインにボーダーを表示 |

## 設定ファイル

| ファイル | 役割 |
|---------|------|
| `~/.config/yazi/yazi.toml` | メイン設定 (レイアウト、opener、プレビュー) |
| `~/.config/yazi/keymap.toml` | キーバインド設定 |
| `~/.config/yazi/theme.toml` | テーマ (Catppuccin Frappe) |
| `~/.config/yazi/init.lua` | プラグイン初期化・UIカスタマイズ |

## Tips

- **cd on quit**: シェルに `function y() { ... }` を設定すると、yaziを終了した時にそのディレクトリに移動できる
- **プレビュー**: bat (シンタックスハイライト)、画像プレビュー (Ghosttyネイティブ) が自動で有効
- **zoxide連携**: `z` キーでzoxideの学習済みディレクトリに瞬時ジャンプ
- **パッケージ管理**: `ya pkg add <repo>` で追加、`ya pkg upgrade` で更新
